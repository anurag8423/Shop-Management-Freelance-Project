# 🛒 Shop Management System (Django)

## 📌 Overview  
This **Shop Management System** is a **Python-Django** based web application designed to streamline product management and billing processes. It provides an intuitive interface to **add products, generate and calculate bills, and maintain records efficiently**. The system also includes **filter-based searching** and **type-based product categorization** for easy navigation and organization.  

## ✨ Features  
- 📦 **Product Management** – Add, update, and delete products effortlessly.  
- 🧾 **Billing System** – Create invoices, calculate total amounts, and maintain transaction records.  
- 🔍 **Filter-Based Search** – Find products quickly using category filters.  
- 🏷️ **Type-Based Categorization** – Organize products under predefined categories for better management.  
- 📊 **Sales Record Management** – Keep track of all transactions and billing history.  

## 🛠️ Tech Stack  
- **Backend**: Django (Python)  
- **Database**: SQLite / PostgreSQL (Configurable)  
- **Frontend**: HTML, CSS, JavaScript  
- **Other**: Bootstrap for styling

## 🚀 Installation & Setup  
1. **Clone the repository**  
   ```bash
   git clone https://github.com/anurag8423/Shop-Management-Freelance-Project.git
   cd Shop-Management-Freelance-Project

2. **Create and activate a virtual environment**  
   ```bash
   python -m venv venv
   venv/bin/activate  # On Windows use venv\Scripts\activate


3. **Install dependencies**  
   ```bash
   pip install -r requirements.txt

4. **Run migrations**  
   ```bash
   python manage.py migrate

5. **Start the development server**  
   ```bash
   python manage.py runserver

***Access the system at http://127.0.0.1:8000/ in your browser.***
